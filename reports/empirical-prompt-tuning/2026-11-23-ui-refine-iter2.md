## Scenario set
- H1（hold-out）: 架空のチケット販売サービスの「払い戻しの確認の段」。題材は [fixtures/ui-refine/](fixtures/ui-refine/)（画面の HTML、仕様、設定ファイル。値はすべて架空）。仕様は見せ方を決めておらず、規約の表示が 1 文ある。画面には、挨拶と前置き、同じ警告の 3 回の繰り返し、「はい／いいえ」の同じ強さのボタン、操作より下の小さな金額、絵文字とグラデーション、入れ子のカード、括弧書きの札を入れてある。
- 実行者に渡したもの: skill のパス、題材の 3 ファイル、ページ全体の画像（幅 375・1280）、evaluation.md の snippet で数えた結果（説明文 318 字、主な操作 2 つ＝「はい」「いいえ」）、説明を隠した画面の画像。
- 記録の前に、題材の銀行名だけを、実在の名前と紛れないよう「サンプル銀行」に替えた（実行者が見た画像では別の架空の名前）。
- 画像の作り方: Playwright で `refund-confirm.html` を開き、`fullPage` で撮る。数えた結果と隠した画像は evaluation.md 3 節の `uiRefineText`（`keep: ".amounts"`）。
- **試しの組み方の誤り**: `keep` を金額の一覧（`.amounts`）だけにしたので、枚数・公演日のタイル、取り消せない結果の警告、規約の表示も説明文として数え（318 字）、実行者に渡した「説明を隠した画像」からも消えていた（Codex のレビュー 2 回目で指摘）。値・C の表示・残す警告を `keep` に入れて数え直すと（`keep: ".amounts, .tile, .legal, .note"`）、説明文 226 字・keep 149 字・主な操作 2 つ（銀行名を替えた後の題材）。実行者は規約の文が 318 字に入っていることを自分で注記しており、見立てと方針の中身は、この誤りで変わる所は見当たらない。この誤りは SKILL.md の Gotchas と evaluation.md の `keep` の説明に書き戻した。
