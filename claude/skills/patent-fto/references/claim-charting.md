# Claim charting・日本法アダプテーション・ハンドオフ・免責

`claude-for-legal/ip-legal/fto-triage` の方法論を本プロジェクト（日本特許FTO）向けに調整。

## Claim chart の作り方（独立クレーム単位）

候補特許ごとに、**独立クレームを limitation（構成要件）単位**で表にする。

| limitation (クレーム要件) | 自社実装の対応箇所 | 判定 | 根拠（pinpoint引用） |
|---|---|---|---|
| 要件A（クレーム原文を逐語） | 自社のどこが対応するか | Disclosed / Suggested / None | クレーム番号・段落 |

ルール:
- **All-elements rule（オールエレメントルール）**: 独立クレームの要件を**1つでも充足しなければ文言侵害は成立しない**。要件を省略しない。
- **独立クレーム最優先**。従属クレームは独立クレームを充足して初めて問題になるので、従属偏重を避ける。
- **feature fallacy 回避**: 明細書の実施例ではなく**クレーム本文の実際の範囲**で判断する。
- **文言侵害(literal)と均等論(DoE)を別行/別欄に分ける**。混ぜない。
- claim construction（クレーム解釈の争い）は**フラグするだけ。解決しない**（弁理士の領域）。
- 間接侵害・誘導侵害・分割侵害（複数主体）は**フラグのみ**。

判定ラベル:
- 特許単位: **High / Medium / Low / None**
- 確度: **screening**（AIスクリーニング段）/ **plausible**（要素一致候補・原文一部未確認）/ **verified**（独立クレーム原文＋法的ステータスを人手確認済）

## 結論の出し方（絶対に「侵害しない」と言わない）

許される結論は次のみ:
- 「自社実装はクレームXの全要素を充足しうる → 弁理士レビュー必須」
- 「1つ以上の要件が明確には存在しない → 弁理士レビュー必須」
- 「クレーム解釈が決定的 → 弁理士の解釈が必要」

GREEN / YELLOW / RED の一文サマリは付けてよいが、それは**トリアージの優先度**であって侵害判断ではない。

## 日本法アダプテーション（US/EU基準を転用しない）

`fto-triage` の基準（du Pont 等）は米/EU寄り。日本特許には以下を別途考慮（いずれも**弁理士判断**）:
- **均等論（最判 H10「ボールスプライン」5要件）**: 本質的部分・置換可能性・置換容易性・公知技術からの容易想到でない・特段の事情なし。AIは「均等論の論点がある」とフラグするまで。
- **間接侵害（特許法101条）**: 「のみ品」「不可欠品＋悪意」等。複数主体（サーバー/ユーザー/発行事業者）に処理が分かれる本件フローでは特に要注意。
- **クレーム種別**: 物・方法・物を生産する方法。「決済方法」クレームと「システム」クレームで侵害主体が変わる。
- **属地主義**: JP特許はJPでの実施のみ、US特許はUSのみ。法域ごとに独立に調べる。CN特許の権利はJP/USに直接効かない。
- **出願中(pending)**: 公開はされても権利未確定。将来の権利化リスクとして別管理（granted版はpendingより狭くなりうる）。

## `[人間必須]` ハンドオフリスト（AIが確定できない事項）

弁理士／山本雄大弁護士に必ず回す:
- 法的ステータス・存続（維持年金未納の失効/復活＝ゾンビ特許、存続期間延長/PTA。AIの「出願から20年」機械カットオフは延長を見落とす）
- 真の権利者・譲渡（assertion entity 保有か）
- 包袋・補正履歴・禁反言（出願経過で限定された範囲）
- 均等論の射程
- パテントファミリーの各国有効性・管轄
- クレーム解釈の breadth / design-around の実現可能性 / litigation-grade判断 / 損害算定
- 意匠(D)・再発行(RE)・植物特許(PP)（本スキルのスコープ外）

## 再発防止：Risk–Confidence Gate（2026-06-09 失敗から学習）

**失敗事例**: US11080687B2 を claim 1 原文を取らずに「cross-chain bridge は任意要件かもしれない」と推測し **High と誤判定**。逐語取得で必須要件と判明し Low（回避）に訂正。

**ルール（必須）**:
- **原文未取得（screening/plausible）の特許を High/Med と断定しない。** 危険・安全どちらにも断定せず `screening・要原本確認` に留める。
- **「必須要件か任意要件か」は独立/従属クレームを原文で読んで確定する。** 読めないなら、その limitation を「任意かも（→侵害）」とも「必須だから外せる（→回避）」とも言わない。All-elements rule は両刃。
- **敵対的検証がリスクを上げてよいのは、クレームを読んで実際の充足経路を見つけたときのみ。** 推測（「〜は任意かも」）でアラートを出さない。
- **High/Med を確定する前に必ず原本を再取得**（Google Patents が落とすなら family page / Espacenet / FPO / BigQuery）。取れなければ screening に降格。
- サマリでは **risk × confidence × verbatim可否** を常にセットで提示する。

## ハルシネーション抑制（精度の核・必須）

- **特許番号は必ず一次DBで実在突合**。開けない番号は使わない。
- **クレームは原文逐語＋pinpoint引用**。fetchで落ちたら別経路で取得するか「未取得」と明記。要約を引用のように書かない。
- **敵対的検証**: 「この特許は回避できている」という結論を、別エージェント/Codexに**反証（refute-by-default）させて**生き残ったものだけ採用。
- 引用ミスは既知の失敗。例: ガイドライン帰属（EPI を CIPA と誤る等）、出典取り違え。**全引用を1件ずつ一次ソースで再確認**。

## 出力に貼る免責ブロック（そのままコピー）

```
【重要・免責】
- 本書はAIによるFTO一次トリアージ（research package）であり、FTO意見書ではない。製品が侵害クリアであるとは結論しない。
- すべての記載は弁理士／弁護士レビュー用のドラフトであり、法的結論ではない。特許クレームの起案は行わない。
- 特許DBを取得できなかった項目は「No patent database search was run」＝提供特許のみに基づく限定出力である。
- 判断基準の一部は米/EU実務に基づく。日本特許法（均等論・間接侵害・J-PlatPat）への適合は別途日本法での確認が必要。
- 本件は法的判断に関わるため、山本雄大弁護士レビューを必須とする（CLAUDE.md 重要規律1）。
- 特定特許を認識した上で対策せず実施を続けると、willful infringement（故意侵害）と評価され損害賠償が増額されうる。今後の方針は弁護士が文書化すること。
```
