## 触らない文言（直したい時は人に聞く）

無い時は「なし」と書く。空欄や「確認中」は未確認として扱い、ui-refine は文言に手を付けない。人にすぐ聞けない作業者が書く時は「確認中」とし、外部に共有した範囲を読み取った根拠（記録の場所）があれば添える。確認中のあいだの例外（範囲の外で、規約・法定の表示にも仕様が決めた文言にも当たらない A の言い換えだけ）は、SKILL.md の 0 節に従う。
